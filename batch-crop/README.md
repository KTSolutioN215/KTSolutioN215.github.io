# 一括トリミング

スクショの余白・ツールバー・メニューバーなど、全画像で同じ位置にある不要部分をまとめてカットするブラウザアプリです。

**使う：** https://ktsolution215.github.io/batch-crop/

## 使い方
1. ZIP・画像・フォルダのどれかを読み込む
2. プレビュー上をドラッグして「残したい範囲」を囲む（数値での微調整、左右余白の自動検出も可）
3. ◀▶で他のページもズレていないか確認
4. 形式と保存方法を選んで「一括カット開始」

## メモ
- 画像はブラウザ内だけで処理され、外部に送信されません
- 数百MB以上の大量画像は、PCのChrome/Edgeで「フォルダに直接保存」が一番安定します
- スマホなどフォルダ保存できない環境では、指定枚数ごとに分けたZIPでダウンロードします
- サイズが違う画像は、1枚目を基準に同じ割合でカットします
